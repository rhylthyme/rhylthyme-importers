# Benchling protocol importer

Convert a Benchling Protocol — Protocol resource, Workflow Task, or
Notebook Entry — into a Rhylthyme program you can follow as a live
timeline at the bench.

> **Status: Phase 4 shipped.** CLI + offline mode (Phase 1), full
> protocol/workflow/entry coverage with multi-track instrument split
> (Phase 2), AES-GCM token storage with connect/disconnect UI
> (Phase 3), web URL-paste import + MCP `import_from_source: "benchling"`
> (Phase 4). Phase 5 adds /connect-page discovery polish and an
> import cache. See [plans/benchling-importer.md](../../plans/benchling-importer.md)
> for the roadmap.

---

## What's the user experience?

You have three entry points after a one-time connect:

| Entry point | Where | When to use |
| --- | --- | --- |
| **Settings → Benchling** | Web app | Connect / disconnect your tenant (one-time). |
| **Upload modal URL paste** | Web app | Paste a Benchling protocol URL. Auto-detects the tenant. |
| **`import_from_source: "benchling"`** | Claude Desktop / MCP | Search your library by keyword; import a protocol by id or URL. |

All three go through the same Phase-1/2 importer, so the resulting
Rhylthyme program is identical regardless of which path you came in by.

## Quickstart (live mode)

### 1. Generate a Benchling API token

In Benchling: **Settings → Account → Workspace API tokens → Create
token**. Copy the token immediately; Benchling won't show it again.

### 2. Connect Benchling in Rhylthyme

Sign in to lab.rhylthyme.com, click your avatar → **Edit profile**,
scroll to **Benchling (optional)**, and paste:

- **Tenant subdomain** — e.g. `acme` for `acme.benchling.com`
- **Personal API token** — what you just generated

Rhylthyme validates the token against `GET /api/v2/users/me` on your
tenant before storing anything. On success you'll see
*"Connected as Your Name @ acme.benchling.com"* with a Disconnect
button.

### 3. Use one of the entry points

**Paste a URL in the Rhylthyme upload box**
```
https://acme.benchling.com/.../protocols/prot_abc/edit
```
Rhylthyme detects the tenant from the URL, looks up your stored token,
and converts the protocol on the fly.

**From Claude Desktop with the lab MCP installed**
```
Search my Benchling library for Western blot protocols
→ import_from_source({source:"benchling", action:"search", query:"Western blot", token: <your Rhylthyme login token>})
```
Then to import a specific match:
```
→ import_from_source({source:"benchling", action:"import", query:"<protocol_id>", token})
→ visualize_schedule(program)
```

## Offline / CLI mode

For development, scripting, or when the live API isn't reachable, the
CLI accepts a saved Benchling Protocol JSON file. The importer module
is the same code path; only the data source differs.

```bash
# Save a Benchling response (or use the bundled fixture)
curl -sS -H "Authorization: Bearer <YOUR_TOKEN>" \
     "https://<TENANT>.benchling.com/api/v2/protocols/<PROTOCOL_ID>" \
     > my-protocol.json

# Convert to a Rhylthyme program
rhylthyme-import-benchling \
  --from-file my-protocol.json \
  --tenant acme \
  --output my-protocol.rhyl.json
```

Bundled fixtures (good for end-to-end demos with no Benchling access):

| Fixture | Shape | Demonstrates |
| --- | --- | --- |
| `pcr-protocol.json` | Protocol | Multi-track split (Bench / Thermocycler / Gel box / UV imager) |
| `workflow-task-elisa.json` | Workflow Task | `fields.Instrument` extraction + missing-duration → indefinite |
| `notebook-entry-blot.json` | Notebook Entry | Block-typed entries; text blocks ignored |
| `missing-durations.json` | Protocol | Three duration paths: explicit / parametric / unparseable |

## What gets converted

See the auto-generated [field-mapping doc](benchling-field-mapping.md)
for the exact table — that file is regenerated by `make docs` from the
live normalizer source.

The short version:

- **Three shapes supported**: Protocol resource, Workflow Task, Notebook
  Entry. Detected by `object_type` (with structural fallback when
  missing).
- **Durations** come from `duration_seconds` → `duration_minutes` →
  the `duration` sub-object → parametric `for N minutes` / `incubate 30
  minutes` in the description. Unparseable steps become `indefinite`
  with a `triggerName` so you mark-complete at the bench.
- **Instruments** become parallel tracks (one per distinct instrument)
  plus `resourceConstraint` entries. Steps without instruments land on
  a default "Bench" track.
- **Predecessors** chain via `afterStep` triggers; the first step gets
  `programStart`. Cross-track dependencies render as dashed edges in
  Rhylthyme's DAG view.

## Security & privacy

- **Tokens are AES-GCM encrypted at rest.** The encryption key
  (`BENCHLING_KEY_ENCRYPTION_KEY`) is a 32-byte server env var; the
  plaintext token only exists in memory during a single request.
- **No INSERT policy** on `user_benchling` for the public roles — the
  table is server-write-only via the service role. Users can SELECT /
  UPDATE / DELETE only their own row via RLS.
- **Validation before persistence**: the connect endpoint calls
  Benchling's `users/me` first and writes the row only if Benchling
  accepts the token.
- **Disconnect leaves Benchling's side untouched** — Rhylthyme can't
  revoke a token on your tenant. To fully sever the link, also delete
  the token in Benchling → Settings → Account → API tokens.

## Operational notes

Token storage, the encryption key and the import cache belong to the
rhylthyme-server deployment and are documented there, not in this package.
Converted programs are cached per `(tenant, protocol_id, revision)`, so a
repeat import of an unchanged protocol skips the live Benchling round-trip.

## Error handling

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| "Token encryption unavailable" on connect | `BENCHLING_KEY_ENCRYPTION_KEY` not set on the server | Add the env var, redeploy |
| "Benchling rejected the credentials" | Wrong tenant subdomain, revoked token, expired token | Generate a fresh token in Benchling and reconnect |
| "You haven't connected `<tenant>.benchling.com` yet" on URL paste | The URL's tenant differs from your connected tenant | Connect that tenant too, or paste a URL on the connected one |
| `import_from_source: "benchling"` returns "Benchling import requires a Rhylthyme access token" | MCP call missing the `token` argument | Call `login` first; pass the returned token as `token` |
| 502 from `/api/url` for a Benchling URL | Live Benchling fetch failed (network, 4xx) | The error body usually carries the Benchling status code; check the protocol id and your token's scope |
| `429` from `import_from_source` | Benchling rate-limited the request | Wait a moment and retry; v1 has no client-side backoff |
